Google's free Mobile-Friendly Test — the page where you pasted a URL and got an instant pass or fail — has not existed since December 2023. Here is what replaced it, and how to test your site now.

Why Google retired its mobile friendly test

Google announced the shutdown in April 2023 and carried it out on December 1, 2023 — retiring the Mobile-Friendly Test, its API and the Mobile Usability report in Search Console at the same time. Its reasoning was simple: far better tools for evaluating mobile usability had appeared since the test first launched, with Chrome's Lighthouse named as the main one.

That does not mean mobile usability stopped mattering. Google's page experience documentation still asks whether content displays well on mobile devices — and points site owners to Lighthouse for the answer. The tool disappeared, but the standard stayed.

What to use now: 4 free tools

PageSpeed Insights is the quickest replacement: paste a URL, stay on the Mobile tab, and read the performance score plus Core Web Vitals. Lighthouse in Chrome DevTools goes deeper — open DevTools, pick the Lighthouse tab, choose Mobile, and run a full audit including accessibility and best practices.

Search Console's URL Inspection shows how Google itself sees your page through its smartphone crawler, with a screenshot and resource errors. And our free mobile friendly test gives you the same core checks — viewport, tap targets, font size and responsive CSS — in seconds, with no signup.

The mobile friendly checklist

A page is mobile friendly when it has a viewport tag set to device width, text at least 16 pixels that reads without zooming, tap targets at least 24 by 24 pixels with enough spacing, no horizontal scrolling, and the same content on mobile as on desktop. Run through that list on your homepage first, then on your highest-traffic pages.

If a page fails, fix the viewport tag first — every other measurement depends on it. Then fix overflow, then tap targets, then speed. Test again after each fix: the fastest way to confirm a fix is to re-run the same test on the same URL.

Frequently asked questions

Does Google's old Mobile-Friendly Test still exist?

No. Google retired it, its API and the Search Console Mobile Usability report on December 1, 2023. The old address search.google.com/test/mobile-friendly returns nothing.

What is the closest replacement?

Google PageSpeed Insights on the Mobile tab, plus Lighthouse in Chrome DevTools for a deeper audit. Our free mobile friendly test covers the same core checks in one step.

Does being mobile friendly affect rankings?

Indirectly but strongly. Since July 2024 Google crawls every site with its smartphone crawler, so content missing on mobile does not exist for Google. Core Web Vitals are also part of its ranking systems.

How often should I test?

After every design change and every new page template — and once a month on your top pages as a routine check.
