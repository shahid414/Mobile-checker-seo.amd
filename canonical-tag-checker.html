What is a canonical tag?

A canonical tag tells Google which URL is the real version of a page when several URLs show the same content — for example with tracking parameters, trailing slashes or http/https versions. Without it, Google splits ranking signals across the duplicates.

Common mistakes: a canonical that points to a different page, a canonical that points to itself on a duplicate, or no canonical at all. This checker shows the tag and whether it matches the URL you tested.

Frequently asked questions

Should every page have a canonical tag?

Yes — even if it points to itself. A self-referencing canonical removes all doubt about which URL is the real one.

What if the canonical points elsewhere?

That tells Google the other page is the real one. That is correct for true duplicates — and a costly mistake if it is not.

Does the canonical have to be absolute?

Yes — use the full URL including https://, not a relative path.
