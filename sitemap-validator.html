What is a sitemap?

A sitemap.xml is a file that lists every important URL on a site so search engines can discover them all — including pages with few or no links pointing to them. It usually lives at example.com/sitemap.xml and is listed in robots.txt.

A good sitemap lists only real, working URLs that return 200, and carries a lastmod date on each entry so Google knows what changed. This validator checks the format, counts the URLs and shows whether lastmod dates are present.

Frequently asked questions

What if a site has no sitemap?

Google can still crawl it through links — but a sitemap speeds up discovery, especially for new or large sites. The validator will tell you no file was found.

What is a sitemap index?

A file that lists several sitemaps instead of URLs — used by large sites. This validator detects indexes and reports how many sitemaps they contain.

How many URLs can a sitemap hold?

Up to 50,000 URLs or 50 MB uncompressed per file. Bigger sites split into several sitemaps under one index.
