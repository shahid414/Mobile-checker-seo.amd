What does the mobile friendly test check?

The test checks the signals that decide whether a page works on a phone: a viewport tag set to device width, responsive CSS with media queries, text large enough to read without zooming, no wide fixed widths that cause sideways scrolling, and a title and H1 heading.

Google retired its own Mobile-Friendly Test in December 2023, but mobile usability still matters — Google ranks the version its smartphone crawler sees. If this test finds issues, fix the viewport tag first, then the layout, then the font sizes.

Frequently asked questions

Is this test really free?

Yes — free, no signup, no account. You can test as many pages as you like.

How is this different from Google's test?

Google retired its Mobile-Friendly Test in December 2023. This tool replaces it with a live check of the same signals, plus a full Lighthouse test when a PageSpeed API key is set.

What should I fix first after a failed test?

Fix the viewport tag first — every other measurement depends on it. Then fix horizontal overflow, then font sizes.
