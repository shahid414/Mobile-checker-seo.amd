Frequently asked questions

Are these tools really free?

Yes — every tool on this page is free with no signup and no account. Test as many pages as you like.

Do I need an API key?

No — except the Website Speed Test, which uses Google PageSpeed Insights. It works without a key for casual use; heavy use needs a free key.

Which tool should I run first?

Start with the Free Mobile Friendly Test on your homepage, then the Mobile SEO Checker, then the Website Speed Test. Those three cover most mobile problems.
