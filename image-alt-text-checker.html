Why does alt text matter?

Alt text is the text alternative for an image: screen readers read it aloud to blind visitors, and browsers show it when an image fails to load. Google also reads it to understand the image — and images with good alt text can rank in image search.

Decorative images should have an empty alt attribute (alt="") so screen readers skip them. Every meaningful image — products, diagrams, screenshots — needs a short, honest description of what it shows.

Frequently asked questions

What makes good alt text?

A short, honest description of what the image shows — usually under 125 characters. Never stuff keywords into it.

Do decorative images need alt text?

No — give them an empty alt attribute (alt="") so screen readers skip them. Only meaningful images need descriptions.

Can alt text help SEO?

Yes — it helps images rank in image search, and it is a small accessibility signal for the page as a whole.
