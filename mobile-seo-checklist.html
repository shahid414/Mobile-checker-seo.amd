Mobile SEO Checklist — 12 Checks for 2026

Twelve checks that cover everything Google weighs on mobile — from the viewport tag to Core Web Vitals. Run through them before your next audit, or after any redesign.

The 12 checks

1. Viewport tag set to width=device-width. 2. No horizontal scrolling at 360 pixels wide. 3. Body text 16 pixels or larger. 4. Tap targets at least 24 by 24 pixels with spacing. 5. Title under 60 characters. 6. Description 120–160 characters. 7. Exactly one H1 per page. 8. Canonical tag pointing to the real URL. 9. Same content, headings and structured data on mobile and desktop. 10. LCP 2.5 seconds or less, INP 200 ms or less, CLS 0.1 or less. 11. Images compressed, sized correctly, with alt text and dimensions. 12. No pop-up covering the content on mobile.

If you run our tools, checks 1–4 come from the mobile friendly test, 5–9 from the mobile SEO checker, 10 from the website speed test, and 11 from the image alt text checker. One run of each covers the whole list.

How to use this checklist

Start on your homepage, then repeat on your five highest-traffic pages — most mobile problems live on templates, so fixing the template fixes every page that uses it. Re-run the tests after each fix: the fastest confirmation is the same test on the same URL.

Make it a habit: after every design change, after every new page template, and once a month on your top pages. A site that passes all twelve rarely has mobile problems.

Frequently asked questions

Which check matters most?

The viewport tag — every other measurement depends on it. Then the mobile-desktop parity check, because missing mobile content is invisible to Google.

How long does the full checklist take?

About ten minutes with our tools: one run of the mobile friendly test, the mobile SEO checker and the speed test per page.

Should I check desktop too?

Yes, but mobile first — Google ranks the mobile version, and most visitors arrive on a phone.
