What does a mobile SEO audit check?

A mobile SEO audit checks whether a page is built for Google's smartphone crawler: a title under 60 characters, a description of 120–160 characters, exactly one H1, a canonical tag, a viewport tag set to device width, valid structured data and images with alt text.

It also checks content length — thin pages rarely rank. Run the audit on your homepage first, then on your highest-traffic inner pages, and fix the failing rows before you worry about anything else.

Frequently asked questions

What is a good mobile SEO score?

80 or above means the page is in good shape. Below 50 means basic signals are missing — start with the title, description and H1.

Is this the same as the mobile friendly test?

No. The mobile friendly test checks how a page works on a phone. This audit checks the SEO signals Google reads on mobile. Use both together.

Does it check Core Web Vitals?

Not on this page — use the Website Speed Test for LCP, INP and CLS, which runs Google Lighthouse.
